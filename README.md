# Clerestoria

A static company site for Clerestoria, with an introduction to Cartopath, for
`clerestoria.com`.

Open `dist/index.html` in a browser to preview it. Edit the homepage in
`dist/index.html` and its styles in `dist/styles.css`.

The `dist/` directory is the document root. Serve it with a static host and
point `clerestoria.com` to that host to go live. There are no dependencies or
build steps.

## UI direction

Use a deep green hero, pale green reading surfaces, and a lime accent for the
main action. Pair Georgia headings with system sans-serif body text. Let real
product screenshots carry the visual story and use simple rows for feature
details. Keep press feedback brief and respect reduced-motion preferences.
